# 사용 방법

1. 앱 상단에 ‘모바일 MVP · v24’가 표시되는지 확인합니다. ‘12개 옷장으로 체험하기’는 개인 옷장과 별도로 제공되는 가상 자료입니다.
2. 실제 사용에서는 생활·활동 지역·취향을 설정하고 보유한 옷을 등록합니다. 사진 분석은 Gemini를 별도로 활성화해야 하며, 분석한 세부 종류·두께·소재를 확인합니다. ‘블랙 팬츠’라는 이름만으로 청바지로 확정하지 않습니다.
3. 오늘 일정에 맞는 추천을 확인합니다. ‘더 편하게’는 날씨와 필수 복장을 지키는 범위에서 편안함이 개선되는 옷 하나를 바꿉니다. 일반 출근에 블랙 진·운동화를 허용하지만 슬리퍼·명확한 운동복은 제외합니다.
4. 상단 사용자/개발자 버튼으로 정보량을 바꿉니다. 개발자 화면은 날씨 출처·시간·후보 점수·제외 이유를 보여주며, 관리자 권한을 주지 않습니다. Gemini를 호출하지 않았다면 토큰을 사용한 것처럼 표시하지 않습니다.
5. 옷장에 유효한 대안이 없으면 안내 이유와 등록 속성을 확인합니다. 착용 선택과 피드백은 선택 사항입니다.

현재 사진·생활·착용 이력은 브라우저에 남습니다. 다른 주소나 브라우저로 옮기기 전 별도 백업·이전 기능이 필요합니다. Supabase의 옷 정보 올리기/가져오기는 속성 일부만 다루며 전체 백업을 대신하지 않습니다. 상세 범위는 [기능 명세](SPEC.md)와 [데이터 이전](DATA-IMPORT.md)을 확인합니다.
