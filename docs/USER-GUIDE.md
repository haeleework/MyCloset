# 사용 방법

2026-10-08 · v27. [배포 화면](https://mycloset-fawn.vercel.app)을 열면 PC 실행 없이 사용할 수 있습니다. 촬영용4335와 저장 확인용4336은 별도로 보존합니다. 주소가 다르면 브라우저의 옷장도 별도입니다.

1. 내 옷장과 생활 설정은 우선 현재 브라우저에 저장됩니다. ‘12개 옷장으로 체험하기’의 가상 옷장은 클라우드로 보내지 않습니다.
2. 초기 화면의 ‘저장한 옷장 가져오기’ 또는 생활과 취향의 ‘옷장 저장 / 가져오기’를 엽니다. 데모 전용 저장 공간에 자동으로 연결되며 회원가입 화면은 없습니다.
3. 처음에는 ‘클라우드 상태 확인’을 누릅니다. 기존 자료가 있으면 가져오기와 현재 기기 자료로 저장 중 원하는 동작을 고릅니다.
4. 저장 동의 체크 후 ‘사진 포함 전체 저장’을 누릅니다. 필요한 사진 전송이 모두 끝나야 저장 완료로 표시합니다. 자동 업로드 기능은 아닙니다.
5. ‘클라우드 자료 가져오기’는 사진을 모두 확인한 다음 현재 기기 자료를 바꿉니다. 변경 전 자료는 같은 브라우저에 별도 백업합니다. ‘가져오기 전 기기 자료 복원’으로 되돌릴 수 있습니다.

다른 화면에서 먼저 저장하면 수정 충돌을 알립니다. ‘클라우드 상태 확인’ 또는 가져오기로 최신 상태를 확인한 뒤 저장합니다. 실패했을 때 저장 완료로 표시하지 않습니다.

같은 브라우저의 접속 정보를 유지해야 같은 데모 저장 공간을 다시 사용할 수 있습니다. 브라우저 데이터를 지우거나 다른 기기에서 열면 이전 저장 공간이 자동 연결되지 않습니다. PC↔휴대폰 공통 계정 동기화는 후속 기능입니다.

촬영용4335의 Gemini·날씨는 활성화 상태를 유지합니다. 연결 검증용4336은 비용 발생 없이 저장만 점검하도록 Gemini·날씨 수집이 꺼져 있습니다.
